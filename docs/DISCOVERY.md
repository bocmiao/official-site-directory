首页快捷按钮会清空旧条件并切换目录。目录下的搜索示例保留当前一级分类，清空细分目录、地区、来源等条件，避免旧筛选挡住示例结果。软件目录仍提供开发、办公、安全等软件用途；在线工具单列可直接在浏览器中使用的服务。

空格分隔的多个关键词支持跨名称、别名、标签、描述组合匹配，例如“游戏 新闻”和“新闻 游戏”均可找到机核。组合匹配要求每个词都命中；不认识的词不会被丢弃或改成宽泛的 OR 检索。常见用途词采用有限、可审阅的等价词组，没有将整个类别展开为推荐站点。保留完整名称、原文、拼音、主机名匹配。

文字搜索先按匹配相关度，再按核验状态及人工目录排序；因此待审核的精确名称可以排在已核对记录的弱描述匹配之前。排序不改变状态。默认搜索 API 仍只返回有效的已核对记录；网页通过显式的“全部可见记录”展示候选。网址核对仍只认已核对的完整主机名。
