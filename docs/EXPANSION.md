## 来源与证据

新增数据来自 Wikidata Query Service，采集日期为 **2026-09-30**，使用实体分类、官网属性 P856，以及存在时的中文名称、中文描述、国家和成立/创建日期。已知解散的实体在查询中排除，但未逐站进行现状或可用性核验。Wikidata 结构化数据采用 CC0-1.0。

- `data/imported/directory-source.json`：查询原文、原始响应哈希、响应行数、采集日期、许可、上一版记录 ID 摘要。
- `data/imported/directory-evidence.json`：实际采用的原始行与 SHA-256；详情页可以查看对应快照。
- `data/imported/directory.json`：整理后的记录、来源标识、标签、中文名称与资料字段。
- `data/licenses/wikidata-cc0.txt`：许可文本。

实体网页可能后续更新，因此网页链接标为“实体记录（可能更新）”。发布时校验本地证据行摘要、实体 ID 和官网地址对应关系，防止记录与快照脱节。该检查证明数据与采集来源一致，不证明来源本身正确。

导入按规范化网址、实体 ID 和同地区名称去重，排除私有地址、占位域名、社交主页、下载文件地址、带查询参数/片段的地址。工具类排除其他类别已识别的实体；教育类排除名称明确为博物馆的记录。网站协议保留来源值，未擅自把 HTTP 改成 HTTPS。

新增 11,831 条全部为 `sourced`（有来源、待核对），不进入可信主机列表，不增加已核验入口，也不进入仅供已核验内容的站点地图。全库仍只有 5 条已核验站点记录、14 个已核验具体入口；另有 34,542 条来源记录和 83 条待核验记录。

## 中文名称与条目资料

新增记录中，5,869 条采用来源提供的中文名；5,565 条使用明确标注“中文参考译名”的本地模型译名；397 条不确定专名保留原文。原文名称均保留供检索和比对，机器译名仍需人工校对，不能当作官方中文名称。

译名使用 Helsinki-NLP/opus-mt-en-zh 的固定转换模型版本，模型及运行参数记录在 `data/localization/directory-model.json`，翻译缓存不进入仓库。新记录的中文资料内联保存，构建时与原有中文资料合并导出。

新条目包含来源实体、查询批次、采集日期、官网字段、分类标签和可获得的国家、成立/创建年份、描述。原有 ROR 机构补充来源公开的 Wikidata、ISNI、FundRef、GRID 标识，Homebrew 软件补充采集时版本；缺失字段留空，不推断联系方式、资质、服务语言或当前最新版本。

## 复现与维护

```sh
node scripts/import-directory.js /path/to/snapshot-dir --dry-run
node scripts/import-directory.js /path/to/snapshot-dir
node scripts/localize-directory.js /path/to/translated.jsonl
npm run audit:data
npm test
```

导入脚本读取各批次的 `批次名.json` 和 `批次名.json.rq` 原始采集文件；脚本固定本次历史采集日期，不应直接当作未来实时采集器使用。完整原始响应与翻译缓存保存在采集工作目录，仓库只保存采用行的证据快照和查询清单。仅凭仓库可校验已收录行，不能重建未采用的原始响应。重新在线执行查询可能返回不同内容。

重新导入会重建本批记录，需要随后运行中文资料脚本恢复参考译名。先使用 dry-run 检查分类分布及排除原因；任一一级分类不足 1,000 条时禁止写入。数据审计和回归测试持续检查分类最低数量、旧记录保留、去重、来源对应关系，以及来源记录不能获得已核验状态。

下一步宜优先提高各分类的人工核验覆盖和中文资料准确率，并补足中国本地服务与薄弱子类，避免只增加同类国际机构数量。
